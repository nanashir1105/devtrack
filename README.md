# DevTrack Helpdesk Demo

A static HTML/CSS/JavaScript helpdesk dashboard with:
- Demo login and logout
- Dashboard ticket counts and status overview
- Ticket create, edit, delete, search, and filtering
- Profile/preferences settings with dark mode
- Browser storage persistence
- Responsive navigation including logout on mobile

## Run
Open `index.html` in a modern browser, or serve this folder with any static web server.
