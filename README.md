# DevTrack — Helpdesk & Issue Tracker

A responsive issue tracking dashboard built with HTML, CSS and JavaScript,
deployed as a static website using GitHub Pages.

## Features

- Dashboard statistics
- Create, edit and delete tickets
- Search by title, category and ticket ID
- Filter tickets by status
- Priority and status indicators
- Responsive layout
- Browser-based data persistence
- Sample tickets for demonstration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages

## Live Demo

https://nanashir1105.github.io/devtrack/

## Run Locally

Open `index.html` in a browser. No build tools or backend required.

## Data Storage

Tickets are saved in localStorage in the current browser. Data is not
shared across devices or users and may be lost if browser storage is cleared.
